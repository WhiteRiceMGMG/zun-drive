APL機能について

pshtjdg --------------------------------------------------------------
input : pioシフト
output : pioシフト

○ミッションの場合
【セミマニュアル】？
・シフトアップ
シフトアップ指令が発行されたとき，以下を満たしているか確認
１．クラッチ開度 > 80%
    クラッチを十分に切っていないと，内部機構を痛めるため．
２．エンジン回転数 > 1500rpm?
    低すぎる回転数でシフトアップするとノッキングやエンストに繋がる．
３．アクセル < 10%
    クラッチを切った状態でアクセルを踏み込んでいるとエンジンが
    空ぶかし状態になる．
成立しない場合，シフト遷移要求を拒否する．


pioからsac最新値を取得する．(生値)

前回値と比較し，
g_u8PshtjdgUpreq シフトアップ要求フラグ
g_u8PshtjdgDwreq シフトダウン要求フラグ
g_u8PshtjdgRvreq リバースギア要求フラグを調停する．
s_u8Pghtjdgsht_o シフト値前回値






・シフトダウン
シフトダウン指令が発行されたとき，以下を満たしているか確認．
１．クラッチ開度 > 80%
２．オーバーレブ回避判定
回転数 = 車速 x ギア比 x ファイナル比 x 単位変換係数(km/h→rpm)
成立しない場合，警告を出し，シフトダウン負荷にする．
また，回転数を自動で同調させるレブマッチング機能もほしい．
車速とターゲットギアから変速後の目標回転数を算出し，空ぶかし指示する．

・ニュートラルへの変更
常に許可．

・リバースギア遷移
リバースギ指令が発行されたとき，以下を満たしているか確認．
１．車速 < 5
２．クラッチ > 90%
３．(ブレーキ = ON)
４．アクセル < 5%
成立しない場合，リバースギアを却下

psystat システム状態管理------------------------------------------------
・クラッチスターターインターロック
以下条件を満たすとき，車両オン
１．イグニッションスイッチ == ON
２．クラッチ > 80%
３．ギアポジション == N
４．車速 < 3km/h
車両が動いているとき，誤ってスタートしたとき，スターターピニオンギアの
噛み込みを抑える．

・電源移行．シャットダウン処理
以下条件を満たすとき，MERLをAFTER_RUNモードへ移行
１．IGSW == OFF
・メイン電源OFF許可条件
以下条件を満たすとき，メイン電源をOFFへする．
１．メモリ書き込み完了
２．故障診断保存済み
３．AFTER_RUN状態が3000ms継続
NVMへ書き込み中に電源が落ちるとデータが破損する．
自己保持メインリレーを制御する．万が一メモリが反応しなくなったときのために
強制タイムアウトを設ける．

preqprcs 要求加工-------------------------------------------------------
・ブレーキオーバーライドシステム
以下条件を満たすとき，アクセル0%に固定
１．アクセル ＞ １０％
２．ブレーキ ＞ ５％
３．１，２の状態が５００ｍｓ以上経過
アクセルが引っかかった場合のフェイルセーフ．

・ペダル入力グラデーション(一次遅れ)
フィルタ後の値Yは，生入力Xに対して一次遅れ(ローパスフィルタ)をかける，
Y後 = αX + (1 - α)Y前
スパイクノイズ除去だけでなく，なまし処理としての役割も持つ



pdiag 故障診断---------------------------------------------------------
thinkpad デスクトップに置いてる草案pdfを参照
・レンジアウトチェック
以下を満たすときセンサー故障確定フラグを立てる
１．センサー電圧 < 0.2
２．センサー電圧 > 4.8
３．１，２が100ms以上継続

・滑り判定条件
以下を満たしたとき，滑りフラグを立てる
| 実際のスピード - 計算したスピード | > クラッチ滑り判定閾値
計算したスピード = (エンジン回転数 x タイヤ周長さ)/(ギア比 x ファイナルギア比)

クラッチが繋がってギアが入っているならば，エンジン回転数と
タイヤの回転速度は決まるはず．これが合わないのはクラッチがすべてっている．



psysprtct システム保護--------------------------------------------------
・オーバーレブ保護
rpm > 6500で燃料噴射完全カット．6300を下回るまでカット継続
・クラッチ焼き付き保護
蓄積熱量を計算し，閾値を超えた場合は出力トルクを強制的にカット
蓄積熱量 = トルク x エンジンとミッションの回転差 x 毎秒足し合わせた合計



psyswarn システム警告-------------------------------------------------
・シフトチェンジインジケータ
エコモード判定
アクセル < 30% であれば2000rpmを超えたらシフトアップ推奨出力
パワーモード判定
アクセル > 80%を超えたら5500rpmを超えるまではシフトアップ推奨出さない
